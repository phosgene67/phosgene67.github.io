This project is an Arduino Nano-based line follower robot designed for fast and accurate path tracking. It uses a PID (Proportional–Integral–Derivative) controller to continuously adjust the motor speeds based on the line position error, ensuring smooth and stable navigation through straight paths and sharp turns. The robot also implements speed ramping (acceleration control), which gradually increases or decreases motor speed to prevent sudden jerks, improve traction, reduce wheel slip, and enhance overall stability. The combination of PID control and acceleration ramping enables the robot to achieve high-speed, precise, and reliable line-following performance.

**Status:** Completed

**Technologies:** Arduino, C++, Control Systems
